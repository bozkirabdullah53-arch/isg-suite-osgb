# Faz 3 Bilinen Sınırlar

- Mevcut 20 soru dağılımı korunur; henüz `5 temel + 15 NACE teknik` değildir.
- Strict mod varsayılan kapalıdır.
- Soru bankası kapsamı yeterli olmayan NACE'lerde strict sınav üretimi bloklanacaktır.
- Sertifika katılım/başarı ön koşulları bu fazın kapsamında değildir.
- Eski sınav snapshotları yeniden yazılmaz.
